Privacy Policy - Worklog Hub

Aktualizováno: 14. května 2026

Tento dokument popisuje, jak rozšíření prohlížeče Worklog Hub ("Rozšíření") nakládá s daty uživatelů. Rozšíření je poskytováno zdarma a běží výhradně v prohlížeči uživatele.

1. Data, která NESHROMAŽĎUJEME

Autor Rozšíření neshromažďuje, nepřenáší, neprodává, nesdílí ani nemá přístup k žádným vašim datům. Neexistuje žádný server provozovaný autorem. Nejsou v něm žádné analytiky, telemetrie, error reportingové služby, reklamní ID ani third-party trackery.

2. Data, která Rozšíření ukládá lokálně

Rozšíření ukládá následující typy dat výhradně do localStorage vašeho prohlížeče na vašem zařízení:

Data Účel
Konfigurace Jira instancí (doména, popisek, barva, prefixy issue klíčů) Aby Rozšíření vědělo, se kterými Atlassian Cloud instancemi má komunikovat.
Drafty worklogů, které ještě nebyly nahrány do Jiry Umožňuje skládat worklogy offline a nahrát je později.
UI preference (jazyk, světlý/tmavý režim, mapování reportů) Personalizace.

Tato data zůstávají na vašem zařízení. Rozšíření je nesynchronizuje do žádné externí služby. Vymazání dat prohlížeče nebo odinstalace Rozšíření je odstraní.

Rozšíření neukládá žádné autentizační údaje - žádné API tokeny, hesla ani OAuth tokeny. Autentizace je založena výhradně na existující session cookie Atlassianu, kterou spravuje prohlížeč nezávisle. Pokud Atlassian session vyprší, uživatel se přihlásí běžným způsobem na webu Atlassianu.

3. Síťová komunikace

Rozšíření odesílá síťové požadavky výhradně na:

  • https://<vaše-instance>.atlassian.net/rest/api/3/... - Jira REST API Atlassian Cloud instancí, které jste si nakonfiguroval/a v Nastavení.

Rozšíření nekomunikuje s žádným jiným serverem. Neprobíhá žádná "phone home" komunikace.

4. Oprávnění a proč o ně žádáme

Oprávnění Účel
host_permissions: https://*.atlassian.net/* Požadováno Chrome / Edge, aby Rozšíření mohlo volat Jira REST API na vašich Atlassian Cloud instancích. Bez něj nemůže Rozšíření číst ani zapisovat vaše worklogy.

Rozšíření nepožaduje žádná jiná oprávnění. Konkrétně nepožaduje: tabs, history, bookmarks, browsing data, identity, cookies, webRequest, downloads, geolocation ani content-script injection do libovolných stránek.

5. Služby třetích stran

Rozšíření komunikuje pouze s Atlassian Cloud (Jira) vaším jménem, s použitím přihlášení, které vy poskytujete. Na tuto komunikaci se vztahují vlastní Privacy Policy Atlassianu: https://www.atlassian.com/legal/privacy-policy. Žádná jiná služba třetí strany od Rozšíření data nedostává.

6. Soukromí dětí

Rozšíření je nástroj pro pracovní produktivitu a není určeno dětem mladším 13 let. Vědomě neshromažďujeme data od dětí.

7. Změny této policy

Pokud se tato policy změní, aktualizovaná verze bude publikována na této stránce a v listingu Chrome Web Store / Edge Add-ons. Datum "Aktualizováno" v záhlaví bude změnu reflektovat.

8. Kontakt

Pro dotazy ohledně této Privacy Policy nebo Rozšíření kontaktujte autora na worklog-hub@email.cz nebo přes support kontakt uvedený v listingu Chrome Web Store / Edge Add-ons.

Shrnutí v jedné větě: Worklog Hub ukládá vaši konfiguraci Jiry a drafty worklogů v localStorage prohlížeče a používá je pouze ke komunikaci s vašimi Atlassian Cloud instancemi - nikde jinde, s ničím jiným.
